# Js Lib

## Instant navigation must merge shared page props

Inertia 3 instant visits replace shared props when explicit pageProps are supplied. Use the pageProps callback and instantWorkspaceProps to merge the supplied shared authentication, Branch, Store and release context before target hints; otherwise the shell crashes before the response arrives. Do not instant-swap an already mounted component (POS ↔ QR Orders), which would temporarily remove the catalog and unmount its cart.
